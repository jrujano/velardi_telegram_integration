2. Regla de Automatización: Código Python (`safe_eval`)

Ejemplo de regla registrada en el modelo velardi.telegram.msg.automation configurada para ejecutarse en la actualización de Pedidos de Venta.

Regla: Orden-Update (sale.order)
Trigger: On Write Tipo: Python Code 
# 1. Validación de registro dentro del contexto localdict
log(f"Iniciando procesamiento para el pedido {record.name}")
record = records[0] if records else None

if not record:
    raise UserError("No se encontró ningún pedido de venta en 'records'.")

_logger.info("Ejecutando acción personalizada para el pedido: %s", record.name)
tareas_creadas = []

# 2. Generación de tareas en el módulo de proyectos de Odoo
for line in record.order_line:
    proyecto = env['project.project'].search([('name', '=', 'Proyectos Web')], limit=1)
    if proyecto:
        fecha_limite = date.today() + timedelta(days=7)
        nueva_tarea = env['project.task'].create({
            'name': f"Servicio contratado: {line.product_id.name} ({record.name})",
            'project_id': proyecto.id,
            'partner_id': record.partner_id.id,
            'date_deadline': fecha_limite,
            'description': f"Tarea generada automáticamente desde el pedido {record.name}.",
        })
        tareas_creadas.append(nueva_tarea.name)

# 3. Notificación a Telegram usando el módulo 'requests' envuelto seguro
if tareas_creadas:
    chat_id = self.chat_id or self.config_id.default_chat_id
    message = (
        "<b>Acción Automática:</b>\n"
        "Se crearon las siguientes tareas:\n"
        + "\n".join(f"• {t}" for t in tareas_creadas)
    )
    payload = {
        "chat_id": chat_id,
        "text": message,
        "parse_mode": "HTML",
        "reply_markup": {              
            "inline_keyboard": [      
                [{'text': 'Opción A', 'callback_data': 'opcion_a'}],
                [{'text': 'Opción B', 'callback_data': 'opcion_b'}],
                [{'text': 'Hablar con soporte', 'callback_data': 'soporte'}]
            ]
        }
    }
    url = f"https://api.telegram.org/bot{self.config_id.bot_token}/sendMessage"
    response = requests.post(url, json=payload, timeout=15)
    
    self.config_id.send_message(message, chat_id=chat_id)
    record.message_post(body=message)

4. Configuración del Bot y Controlador de Webhooks

El módulo expone un endpoint seguro no autenticado para la recepción de actualizaciones en tiempo real y gestiona la vinculación de la URL mediante la API oficial.

velardi.telegram.config

Gestión centralizada del Bot Token, modo simulación, botones interactivos e inscripción del webhook. 

def action_register_webhook(self):
    base_url = self.env['ir.config_parameter'].sudo().get_param('web.base.url')
    webhook_endpoint = f'{base_url}/telegram/webhook/{self.id}'
    url = f'https://api.telegram.org/bot{self.bot_token}/setWebhook'
    response = requests.post(
        url, json={'url': webhook_endpoint}, timeout=10
    )
telegram_webhook.py Controller

Endpoint HTTP encargado de recibir los JSON desde Telegram y delegarlos al Mixin de procesamiento. 

@http.route('/telegram/webhook/<int:bot_id>', type='json', auth='none', csrf=False, methods=['POST'])
def telegram_webhook(self, bot_id, **kwargs):
    bot_config = request.env['velardi.telegram.config'].sudo().browse(bot_id)
    update_data = request.get_json_data()
    if bot_config.save_notificaction:
        request.env['velardi.telegram.mixin'].sudo()._process_incoming_update(update_data)
    return {'ok': True}

6. Mensajes de Bienvenida, Registro y Error

Configuración de mensajes automáticos enviados durante el flujo de interacción del bot: bienvenida, registro exitoso y errores.

Mensaje de Bienvenida

Se envía al ejecutar /start.

  • welcome_message_type: text / payload
  • welcome_message: Contenido
{
  "parse_mode": "HTML",
  "text": "<b> BIENVENIDO </b>\n\nHola, <b>{{first_name}}</b>",
  "reply_markup": {
    "inline_keyboard": [
      [{"text": "🔗 Vincular",
        "callback_data": "start_reg"}],
      [{"text": "📲 WhatsApp",
        "url": "https://wa.me/56982510043"}]
    ]
  }
}
Registro Exitoso

Se envía cuando el registro se completa correctamente.

  • successful_registration_message_type: text / payload
  • successful_registration_message: Contenido
{
  "text": "✅ Registro exitoso. ¡Bienvenido!",
  "parse_mode": "HTML"
}
Error de Registro

Se envía cuando falla un intento de registro.

  • error_registration_message_type: text / payload
  • error_registration_message: Contenido
{
  "text": "❌ Error en el registro. Intenta nuevamente.",
  "parse_mode": "HTML"
}
